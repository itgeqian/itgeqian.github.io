CodeBuddy + 腾讯云ClouaseAI编程实战

一、课程准备与环境搭建

在开始项目开发之前，确保你的环境已准备就绪。

1.课程所需准备

准备项 说明
Node.js 必须安装，用于运行 JavaScript 环境。
CodeBuddy IDE 腾讯自家的 AI 编程 IDE，本课程核心工具。
腾讯云 CloudBase 开通云开发环境，用于后端开发、数据库、存储及部署。
DeepSeek API Key 注册 DeepSeek 开放平台，获取 API Key 用于 AI 对话功能。

2.初始化项目结构

  1. 新建项目文件夹：bilibili-analysisi
  2. 使用 CodeBuddy 打开该项目文件夹。
  3. 创建基础文件和目录结构：
    1. scripts/index.js (爬虫脚本文件)
    2. dist/ 目录
    3. dist/images/ 目录 (存放封面图)
    4. data.json (存放爬取到的原始数据)

五、项目部署

最后，我们将使用腾讯云 CloudBase 的云托管服务将项目部署上线。

  1. 准备 Dockerfile： 根据 Next.js 部署文档，将所需的 Dockerfile 添加到项目根目录。
  2. 选择部署方式： 推荐使用 Git 仓库部署（最佳实践），本课程演示的是最简单的本地代码部署。
  3. 上传代码： 进入 CloudBase 控制台的云托管，选择新建服务，上传本地代码（包含 Dockerfile）。
  4. 配置环境：
    1. 配置端口为 3000。
    2. 配置项目所需的环境变量（包括 DEEPSEEK_API_KEY 等）。
  5. 自定义域名与证书（可选）： 为了更专业的访问体验，可以在 CloudBase 中配置自定义域名，并申请 SSL 证书。
